# GEO / AEO : auditer la visibilité générative d'une marque

Le SEO classique optimise pour des liens. Le GEO (Generative Engine Optimization) /
AEO (Answer Engine Optimization) optimise pour être **cité dans les réponses** des IA.

## Méthode
1. **Batterie de requêtes clients réelles** : les questions que posent vraiment les gens
   (« meilleur X près de Y », « horaires », « avis », comparaison concurrents, « que faire »).
2. **Interroger plusieurs moteurs** : ChatGPT, Gemini, Perplexity, Google AI Overviews,
   plus la recherche web. Capturer ce que chacun répond.
3. **Grille de score** : présence, exactitude, part de voix vs concurrents, sources citées,
   erreurs factuelles.
4. **Leviers, par effort** : données structurées schema.org cohérentes, Google Business Profile,
   Wikidata / Wikipédia, contenu Q/R, llms.txt, avis réels. Uniformiser d'abord les données
   incohérentes (les moteurs hésitent quand les sources se contredisent).
5. **Cadence mensuelle** : refaire l'audit pour mesurer le déplacement de part de voix.

## Règle
Uniquement de la vraie information rendue trouvable. Aucun faux signal, aucun faux avis.
